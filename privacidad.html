Qué datos se leen

Con la autorización del dueño de cada canal de YouTube, la herramienta lee, solo en modo lectura:

  • estadísticas de YouTube Analytics del canal: vistas, tiempo de visualización y curva de retención de cada video (permiso yt-analytics.readonly);
  • la lista de videos del canal, con su título, su fecha y su duración (permiso youtube.readonly).

No lee correos, contactos ni datos de otras personas. No puede publicar, editar ni borrar nada en YouTube.

Para qué se usan

Solo para analizar el rendimiento de los propios videos del dueño de los canales y mejorar los videos siguientes.

Dónde se guardan

En la computadora del dueño de los canales. Los permisos de acceso de Google también se guardan ahí, en un archivo privado. No se suben a servidores de terceros.

Con quién se comparten

Con nadie. No se venden ni se usan para publicidad.

Uso limitado

El uso y la transferencia a cualquier otra app de la información recibida de las API de Google se ajustarán a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Servicios de la API de YouTube

Esta herramienta usa los Servicios de la API de YouTube. Al autorizarla, aceptas las Condiciones del Servicio de YouTube; la Política de Privacidad de Google se aplica a los datos que maneja Google.

Cómo quitar el acceso y borrar los datos

Puedes quitarle el acceso cuando quieras en myaccount.google.com/permissions (Curva de retencion → Quitar acceso). Desde ese momento la herramienta no lee nada más. Para borrar lo que ya se guardó, escribe al contacto de abajo.

Privacy policy

Curva de retención · Last updated: October 29, 2026

What data is read

With the authorization of each YouTube channel’s owner, the tool reads, read-only:

  • the channel’s YouTube Analytics statistics: views, watch time and each video’s audience retention curve (yt-analytics.readonly scope);
  • the channel’s video list, with title, date and duration (youtube.readonly scope).

It does not read email, contacts or anyone else’s data. It cannot publish, edit or delete anything on YouTube.

How it is used

Only to analyze the performance of the channel owner’s own videos and to improve future videos.

Where it is stored

On the channel owner’s computer. Google access tokens are stored there too, in a private file. Nothing is uploaded to third-party servers.

Who it is shared with

No one. It is not sold or used for advertising.

Limited Use

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By authorizing it, you agree to the YouTube Terms of Service; the Google Privacy Policy applies to data handled by Google.

Revoking access and deleting data

You can revoke access at any time at myaccount.google.com/permissions. From then on the tool reads nothing more. To delete data already stored, write to the contact below.
